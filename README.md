# swampfir3 portfolio

A lightweight, responsive personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Preview locally
Open `index.html` in your browser. No build tools are required.

## Publish on GitHub Pages
1. Create a public repository named `swampfire3.github.io` under the GitHub account `swampfire3`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the deployment. The expected URL is `https://swampfire3.github.io/`.

## Before publishing
- Check the project description and repository link in `index.html`.
- Update the operating systems and editor details to match your current setup.
- Add any additional projects and contact details you want public.
- Remove any details you don't want to share.

## Connect `swampfir3.is-a.dev`
After the site is live and meets the is-a.dev requirements, follow the official instructions at https://docs.is-a.dev/quickstart/ and create `domains/swampfir3.json` in your fork of https://github.com/is-a-dev/register. The expected CNAME target for GitHub Pages is `swampfire3.github.io`. Follow the repository's current validation rules and pull request template.
